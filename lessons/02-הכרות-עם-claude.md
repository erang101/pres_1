# שיעור 2: הכרות עם Claude

## מי זה Claude?

**Claude** הוא עוזר בינה מלאכותית (AI) שנבנה על ידי חברת Anthropic.

### מה זה בינה מלאכותית (AI)?

בינה מלאכותית היא תוכנה שיכולה:
- להבין שפה אנושית
- לענות על שאלות
- לעזור בפתרון בעיות
- ללמוד מדוגמאות

### מה Claude יודע לעשות?

| יכולת | דוגמה |
|-------|-------|
| לענות על שאלות | "מה הבירה של צרפת?" |
| להסביר מושגים | "הסבר לי מה זה פוטוסינתזה" |
| לכתוב טקסטים | "כתוב מייל מקצועי" |
| לעזור בתכנות | "תקן את הבאג בקוד הזה" |
| לתרגם | "תרגם את זה לאנגלית" |

---

## מה זה Claude Code?

**Claude Code** הוא כלי מיוחד שמאפשר ל-Claude לעזור לך לתכנת!

### ההבדל בין Claude רגיל ל-Claude Code:

| Claude רגיל | Claude Code |
|-------------|-------------|
| עובד דרך אתר או אפליקציה | עובד ישירות על המחשב שלך |
| יכול רק לדבר איתך | יכול גם לקרוא ולכתוב קבצים |
| נותן עצות | גם מבצע את העבודה |

### מה Claude Code יכול לעשות?

1. **לקרוא קוד קיים** - להבין מה כתוב בקבצים שלך
2. **לכתוב קוד חדש** - ליצור קבצים ותוכניות
3. **לתקן באגים** - למצוא ולתקן שגיאות
4. **להסביר קוד** - להסביר מה קוד מסוים עושה
5. **להריץ פקודות** - להפעיל תוכניות על המחשב

---

## איך מדברים עם Claude Code?

מדברים איתו בעברית (או בכל שפה אחרת) - בדיוק כמו שמדברים עם אדם!

### דוגמאות לבקשות:

```
"תראה לי מה יש בתיקייה הזו"
```

```
"צור קובץ חדש בשם hello.py"
```

```
"הסבר לי מה הקוד הזה עושה"
```

```
"תקן את השגיאה בקובץ"
```

---

## למה Claude Code טוב למתחילים?

1. **לא צריך לזכור פקודות** - פשוט אומרים מה רוצים
2. **מסביר תוך כדי** - אפשר לבקש הסברים
3. **סבלני** - אפשר לשאול את אותה שאלה כמה פעמים
4. **עוזר ללמוד** - לא רק עושה, גם מלמד

### דוגמה לשיחה:

```
את/ה: "מה זה משתנה בתכנות?"

Claude: "משתנה הוא כמו קופסה עם שם שמחזיקה מידע.
         למשל, x = 5 שומר את המספר 5 בקופסה בשם x"

את/ה: "תראה לי דוגמה בקוד"

Claude: "בטח! הנה דוגמה:
         name = 'דני'
         age = 25
         עכשיו יש לנו שני משתנים - name ו-age"
```

---

## מה Claude Code לא יכול לעשות?

- **לגלוש באינטרנט** בצורה חופשית
- **לזכור שיחות קודמות** (כל שיחה מתחילה מחדש)
- **לעשות דברים מסוכנים** - יש לו הגבלות אבטחה

---

## סיכום

- Claude = עוזר AI שמבין שפה אנושית
- Claude Code = Claude שיכול לעבוד על המחשב שלך
- מדברים איתו בשפה רגילה
- הוא יכול לקרוא, לכתוב, להסביר ולהריץ קוד
