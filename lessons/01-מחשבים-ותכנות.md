# שיעור 1: מחשבים ותכנות

## מה זה בעצם מחשב?

מחשב הוא מכונה שיודעת לעשות שלושה דברים בסיסיים:

1. **לקבל מידע** (קלט) - מהמקלדת, מהעכבר, מקבצים
2. **לעבד מידע** (חישוב) - לחשב, להשוות, לארגן
3. **להוציא מידע** (פלט) - להציג על המסך, לשמור לקובץ

### דוגמה פשוטה:
כשאתה כותב "2 + 2" במחשבון:
- **קלט**: הספרות 2, 2 והסימן +
- **עיבוד**: המחשב מחשב את התוצאה
- **פלט**: המחשב מציג 4

---

## מה זה תכנות?

**תכנות** = לתת למחשב הוראות מדויקות מה לעשות.

המחשב לא יודע לחשוב בעצמו. הוא רק יודע לבצע הוראות.
כמו מתכון למאפה - אם תכתוב "הוסף קמח", הוא יוסיף קמח.
אם תשכח לכתוב "הוסף סוכר", העוגה תהיה בלי סוכר.

### למה זה נקרא "שפת תכנות"?

כי אנחנו צריכים לדבר עם המחשב בשפה שהוא מבין.
יש הרבה שפות תכנות, למשל:

| שפה | למה היא טובה |
|-----|--------------|
| Python | קלה ללמידה, פופולרית מאוד |
| JavaScript | לאתרי אינטרנט |
| Java | לאפליקציות גדולות |

---

## מה זה קוד?

**קוד** = ההוראות שאנחנו כותבים בשפת תכנות.

### דוגמה לקוד פשוט (בשפת Python):

```python
print("שלום עולם!")
```

מה קורה כאן?
- `print` = הוראה להציג משהו על המסך
- `"שלום עולם!"` = הטקסט שנרצה להציג
- התוצאה: על המסך יופיע "שלום עולם!"

---

## למה ללמוד תכנות?

1. **לפתור בעיות** - לבנות כלים שעוזרים לך
2. **אוטומציה** - לגרום למחשב לעשות דברים משעממים במקומך
3. **יצירתיות** - לבנות אתרים, משחקים, אפליקציות
4. **עבודה** - מתכנתים מאוד מבוקשים

---

## סיכום

- מחשב = מכונה שמבצעת הוראות
- תכנות = לכתוב הוראות למחשב
- קוד = ההוראות בשפת תכנות
- שפת תכנות = השפה שבה מדברים עם המחשב

---

2. למה מחשב צריך הוראות מדויקות?
3. מה ההבדל בין קוד לשפת תכנות?
