# שיעור 4: עבודה עם קבצים ותיקיות

## למה זה חשוב?

Claude Code עובד עם קבצים במחשב שלך.
כדי לתקשר איתו טוב, חשוב להבין איך מחשב מאחסן מידע.

---

## מה זה קובץ?

**קובץ** = מיכל שמחזיק מידע.

כמו דף נייר - יש לו:
- **שם** (למשל: "מכתב")
- **סיומת** שמראה את הסוג (למשל: ".txt")
- **תוכן** (מה כתוב בפנים)

### סוגי קבצים נפוצים:

| סיומת | סוג | שימוש |
|-------|-----|-------|
| `.txt` | טקסט | טקסט פשוט |
| `.py` | Python | קוד Python |
| `.js` | JavaScript | קוד JavaScript |
| `.html` | HTML | דפי אינטרנט |
| `.css` | CSS | עיצוב אתרים |
| `.json` | JSON | נתונים מאורגנים |
| `.md` | Markdown | טקסט מעוצב (כמו השיעור הזה!) |

---

## מה זה תיקייה?

**תיקייה** (או "ספרייה") = מקום שמכיל קבצים או תיקיות אחרות.

כמו תיקייה אמיתית במשרד - אפשר לשים בה דפים (קבצים) או תיקיות קטנות יותר.

### מבנה עץ:

```
המחשב שלי/
├── מסמכים/
│   ├── עבודה/
│   │   ├── דוח.txt
│   │   └── חשבונית.pdf
│   └── אישי/
│       └── מתכונים.txt
├── תמונות/
│   ├── חופשה/
│   └── משפחה/
└── הורדות/
```

---

## מה זה נתיב (Path)?

**נתיב** = הכתובת המלאה של קובץ או תיקייה.

### דוגמאות:

| מערכת | דוגמה לנתיב |
|-------|-------------|
| Windows | `C:\Users\dani\Documents\file.txt` |
| Mac/Linux | `/home/dani/documents/file.txt` |

### חלקי הנתיב:

```
/home/dani/projects/my-app/index.html
│     │     │        │      └── שם הקובץ
│     │     │        └── תיקיית הפרויקט
│     │     └── תיקיית הפרויקטים
│     └── תיקיית המשתמש
└── התיקייה הראשית
```

---

## מה זה Terminal/Command Line?

**Terminal** = חלון שבו כותבים פקודות למחשב בטקסט.

במקום ללחוץ עם העכבר, כותבים מה לעשות:

### פקודות בסיסיות:

| פקודה | מה היא עושה | דוגמה |
|-------|-------------|-------|
| `ls` | הצג קבצים בתיקייה | `ls` |
| `cd` | עבור לתיקייה | `cd Documents` |
| `pwd` | הצג היכן אני נמצא | `pwd` |
| `mkdir` | צור תיקייה חדשה | `mkdir project` |
| `cat` | הצג תוכן קובץ | `cat file.txt` |

### למה זה חשוב?

Claude Code משתמש ב-Terminal בשבילך!
כשאתה אומר "תראה מה יש בתיקייה", הוא מריץ פקודות כמו `ls`.

---

## מה זה פרויקט?

**פרויקט** = תיקייה שמכילה את כל הקבצים של תוכנה או אתר.

### מבנה פרויקט טיפוסי:

```
my-website/
├── index.html      ← העמוד הראשי
├── style.css       ← עיצוב האתר
├── script.js       ← קוד JavaScript
├── images/         ← תמונות
│   ├── logo.png
│   └── background.jpg
└── README.md       ← הסבר על הפרויקט
```

---

## קבצים חשובים להכיר

| קובץ | מה זה |
|------|-------|
| `README.md` | הסבר על הפרויקט |
| `package.json` | הגדרות לפרויקט JavaScript |
| `requirements.txt` | רשימת חבילות Python |
| `.gitignore` | קבצים ש-Git יתעלם מהם |
| `.env` | הגדרות סודיות (סיסמאות) |

---

## תיקייה נוכחית (Working Directory)

כש-Claude Code עובד, הוא נמצא בתיקייה מסוימת.
זו ה"תיקייה הנוכחית" שלו.

```
את/ה: "תראה מה יש פה"
Claude Code: (מריץ ls בתיקייה הנוכחית)
```

### אפשר לשנות תיקייה:

```
את/ה: "עבור לתיקייה src"
Claude Code: (עובר לתיקייה src)
```
