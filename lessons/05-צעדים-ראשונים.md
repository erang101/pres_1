# שיעור 5: צעדים ראשונים עם Claude Code

## איך מתחילים?

### התקנת Claude Code

Claude Code מותקן דרך ה-Terminal. ההתקנה נראית ככה:

```bash
npm install -g @anthropic-ai/claude-code
```

(לא צריך לעשות את זה עכשיו - זה רק להכיר)

### הפעלה

כותבים בטרמינל:

```bash
claude
```

וזהו! Claude Code מוכן לעבוד.

---

## איך לבקש דברים מ-Claude Code

### עקרונות חשובים:

1. **היה ברור** - אמור מה בדיוק אתה רוצה
2. **תן הקשר** - הסבר למה אתה צריך את זה
3. **שאל שאלות** - אם משהו לא ברור

### דוגמאות לבקשות טובות:

| בקשה לא ברורה | בקשה ברורה |
|--------------|------------|
| "תעשה אתר" | "צור דף HTML פשוט עם כותרת 'שלום עולם'" |
| "תתקן את זה" | "יש שגיאה בשורה 15, התוכנית לא רצה" |
| "תסביר" | "הסבר מה הפונקציה calculate_total עושה" |

---

## פקודות מיוחדות (Slash Commands)

Claude Code מכיר פקודות מיוחדות שמתחילות ב-`/`:

| פקודה | מה היא עושה |
|-------|-------------|
| `/help` | הצג עזרה |
| `/clear` | נקה את השיחה |
| `/compact` | צמצם את השיחה (חוסך זיכרון) |

---

## דוגמה לשיחה ראשונה

```
את/ה: שלום! אני חדש פה. מה אתה יכול לעשות?

Claude: שלום! אני יכול לעזור לך עם:
        - לקרוא ולכתוב קבצים
        - להסביר קוד
        - לכתוב קוד חדש
        - לתקן באגים
        - להריץ פקודות

        במה תרצה להתחיל?

את/ה: בוא ניצור קובץ פשוט

Claude: בשמחה! איזה סוג קובץ תרצה?
        - קובץ טקסט פשוט (.txt)
        - קובץ Python (.py)
        - דף HTML (.html)
        - משהו אחר?

את/ה: קובץ טקסט עם המילים "שלום עולם"

Claude: יצרתי קובץ בשם hello.txt עם התוכן "שלום עולם".
        הקובץ נמצא בתיקייה הנוכחית.
```

## מה Claude Code שואל אישור לפני שעושה?

Claude Code שואל אישור לפני:

| פעולה | למה שואל |
|-------|----------|
| כתיבת קבצים | כדי לא לדרוס משהו חשוב |
| מחיקת קבצים | מחיקה זה לא הפיך |
| הרצת פקודות | כדי לוודא שזה בטוח |
| התקנת תוכנות | כי זה משפיע על המחשב |

### איך זה נראה:

```
Claude: אני רוצה ליצור את הקובץ index.html
        האם לאשר?
        [Yes] [No]
```

## טיפים למתחילים

### 1. התחל קטן

```
❌ "תבנה לי אפליקציה מלאה לניהול משימות"
✓ "צור קובץ Python שמדפיס שלום עולם"
```

### 2. שאל שאלות

```
"לא הבנתי מה הקוד הזה עושה, אתה יכול להסביר?"
```

### 3. בקש הסברים

```
"אני רוצה ללמוד, אז תסביר לי כל שלב"
```

### 4. אל תפחד לטעות

```
"עשיתי משהו לא נכון, אתה יכול לעזור לתקן?"
```

### 5. היה ספציפי עם שגיאות

```
❌ "זה לא עובד"
✓ "כשאני מריץ את הקוד, מופיעה שגיאה: TypeError on line 5"
```

## מה לעשות כשמשהו לא עובד?

1. **תאר את הבעיה** - מה ניסית לעשות?
2. **ספר מה קרה** - מה הודעת השגיאה?
3. **שתף קוד** - Claude Code יכול לראות את הקבצים
4. **בקש עזרה** - "אתה יכול לעזור לי להבין למה זה לא עובד?"
