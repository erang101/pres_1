## 1. משתנים (Variables)

**משתנה** = קופסה עם שם שמחזיקה מידע.

### דוגמאות:

```python
# שמירת שם
name = "דני"

# שמירת מספר
age = 25

# שמירת מחיר
price = 99.90
```

### למה זה שימושי?

במקום לכתוב את אותו דבר שוב ושוב, שומרים אותו במשתנה:

```python
# בלי משתנה - צריך לכתוב שוב ושוב
print("שלום דני")
print("מה שלומך דני?")
print("להתראות דני")

# עם משתנה - קל לשנות
name = "דני"
print("שלום " + name)
print("מה שלומך " + name + "?")
print("להתראות " + name)
```

## 2. סוגי מידע (Data Types)

למידע יש סוגים שונים:

| סוג | בעברית | דוגמה |
|-----|--------|-------|
| String | טקסט/מחרוזת | `"שלום"` |
| Integer | מספר שלם | `42` |
| Float | מספר עשרוני | `3.14` |
| Boolean | אמת/שקר | `True` או `False` |
| List | רשימה | `[1, 2, 3]` |

### למה זה חשוב?

```python
# מספרים אפשר לחבר מתמטית
x = 5 + 3      # תוצאה: 8

# טקסט מתחבר אחרת
y = "5" + "3"  # תוצאה: "53"
```

---

## 3. פונקציות (Functions)

**פונקציה** = קבוצת הוראות עם שם, שאפשר להשתמש בה שוב ושוב.

### דמיינו מתכון:

```
מתכון: להכין תה
1. לחמם מים
2. לשים שקית תה בכוס
3. לשפוך מים חמים
4. לחכות 3 דקות
```

בתכנות זה נראה כך:

```python
def make_tea():
    heat_water()
    put_tea_bag()
    pour_water()
    wait(3)
```

### למה זה שימושי?

במקום לכתוב את אותן הוראות 10 פעמים, כותבים פונקציה פעם אחת וקוראים לה:

```python
# במקום לכתוב את כל ההוראות 3 פעמים
make_tea()  # כוס ראשונה
make_tea()  # כוס שנייה
make_tea()  # כוס שלישית
```

## 4. תנאים (Conditions)

**תנאי** = לעשות משהו רק אם משהו נכון.

### בחיים האמיתיים:
"**אם** יורד גשם, **אז** קח מטריה"

### בקוד:

```python
weather = "rain"

if weather == "rain":
    print("קח מטריה!")
else:
    print("יום נעים!")
```

### סימנים חשובים:

| סימן | משמעות |
|------|--------|
| `==` | שווה ל |
| `!=` | לא שווה ל |
| `>` | גדול מ |
| `<` | קטן מ |
| `>=` | גדול או שווה |
| `<=` | קטן או שווה |

---

## 5. לולאות (Loops)

**לולאה** = לחזור על פעולה כמה פעמים.

### בחיים האמיתיים:
"תשטוף את כל הצלחות בכיור"

### בקוד:

```python
# לעשות משהו 5 פעמים
for i in range(5):
    print("שלום!")

# לעבור על רשימה
fruits = ["תפוח", "בננה", "תפוז"]
for fruit in fruits:
    print(fruit)
```

---

## 6. הערות (Comments)

**הערה** = טקסט שהמחשב מתעלם ממנו, מיועד לבני אדם.

```python
# זו הערה - המחשב מתעלם מהשורה הזו

name = "דני"  # אפשר גם בסוף שורה

"""
זו הערה
על כמה
שורות
"""
```

### למה זה שימושי?

- להסביר מה הקוד עושה
- להשאיר תזכורות
- לעזור לאחרים להבין את הקוד

---

## סיכום מושגים

| מושג | הסבר קצר | דוגמה |
|------|----------|-------|
| משתנה | קופסה עם שם | `x = 5` |
| סוג מידע | מה סוג המידע | טקסט, מספר, רשימה |
| פונקציה | קבוצת הוראות | `def say_hello():` |
| תנאי | אם... אז... | `if x > 0:` |
| לולאה | חזרה על פעולה | `for i in range(5):` |
| הערה | הסבר בקוד | `# זו הערה` |
