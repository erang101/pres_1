# שיעור 6: תרגול מעשי

## הגיע הזמן להתנסות!

בשיעור הזה נתרגל את מה שלמדנו. כל תרגיל מתחיל קל ונהיה יותר מורכב.

---

## תרגיל 1: שלום עולם

### המטרה:
ליצור קובץ פשוט ולראות את התוכן שלו.

### מה לבקש מ-Claude Code:

```
"צור קובץ בשם hello.txt עם הטקסט: שלום עולם! זה הקובץ הראשון שלי."
```

### אחרי זה בקש:

```
"תראה לי את התוכן של hello.txt"
```

### מה למדת?
- איך ליצור קובץ
- איך לראות תוכן קובץ

---

## תרגיל 2: תוכנית Python ראשונה

### המטרה:
ליצור ולהריץ תוכנית Python.

### מה לבקש:

```
"צור קובץ Python בשם greet.py שמבקש מהמשתמש את השם שלו ומדפיס ברכה"
```

### דוגמה למה שצריך לקרות:

```

```

### אחרי זה בקש:

```
"הסבר לי מה כל שורה בקוד עושה"
```

### מה למדת?
- איך ליצור תוכנית
- איך לקבל קלט מהמשתמש
- איך להדפיס פלט

### מה לבקש:

```
"צור מחשבון פשוט ב-Python שמקבל שני מספרים ומציג את הסכום שלהם"
```

### שדרוג:

```
"עכשיו תוסיף גם חיסור, כפל וחילוק"
```

### מה למדת?

- איך להרחיב תוכנית קיימת

## תרגיל 4: רשימת קניות

### המטרה:
ליצור תוכנית שמנהלת רשימת קניות.

### מה לבקש:

```
"צור תוכנית Python לניהול רשימת קניות.
המשתמש יכול להוסיף פריטים, להציג את הרשימה, ולמחוק פריטים."
```

### דוגמה למה שצריך לקרות:

```
=== רשימת קניות ===
1. הוסף פריט
2. הצג רשימה
3. מחק פריט
4. יציאה

בחר אפשרות: 1
הכנס פריט: חלב
חלב נוסף לרשימה!
```

### מה למדת?
- עבודה עם רשימות
- תפריט אינטראקטיבי
- לולאות

---

### שדרוג:

### מה למדת?
- מבנה בסיסי של HTML
- עיצוב פשוט עם CSS
