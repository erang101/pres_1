# Israel Bank Service Points (OSINT)

This repository includes:

- `bank_service_report.md` — detailed per-bank service-point and telephone-service report.
- `generate_map.py` — script to regenerate the map SVG.
- `israel_bank_service_points_map.svg` — map deliverable.
- `index.html` + `styles.css` — static web app entry page for publishing.

## Web App Entry

Open `index.html` locally, or publish this repo with GitHub Pages and use `/index.html` as the landing page.
